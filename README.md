# React Notes App

A simple Notes Application built using React and Vite. This project is being developed as a team project to practice React fundamentals and frontend development.

## Features — Phase 1

- Create new notes with a title and description.
- Display all saved notes.
- Edit existing notes.
- Delete notes.
- Automatically save notes using browser LocalStorage.
- Responsive basic layout and styling.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Browser LocalStorage

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Anjali-Anjali-2005/React-Notes-App.git
   ```

2. Open the project folder:

   ```bash
   cd React-Notes-App
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
